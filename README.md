# Discord Bot: ระบบส่งรูป + อนุมัติแต้ม (Loop/Airdrop)

## ฟีเจอร์
- `/setplayers` — [แอดมิน] เด้งกล่องข้อความให้วางรายชื่อผู้เล่นทั้งหมดทีเดียว (บรรทัดละ 1 ชื่อ) สะดวกกว่าเพิ่มทีละคน
- `/addplayer ชื่อ` — [แอดมิน] เพิ่มชื่อผู้เล่นเข้าลิสต์ทีละคน
- `/removeplayer ชื่อ` — [แอดมิน] ลบชื่อออกจากลิสต์ (พิมพ์บางส่วนแล้วเลือกจากที่ระบบเดาให้ได้)
- `/renameplayer ชื่อเดิม ชื่อใหม่` — [แอดมิน] เปลี่ยนชื่อผู้เล่น โดยแต้มสะสมเดิมยังอยู่ครบ (ใช้ตอนแก้จาก "คนที่1" เป็นชื่อจริง)
- `/players` — ดูรายชื่อผู้เล่นทั้งหมดที่มีในระบบ
- `/loop` — เลือกกิจกรรม (/Airdrop/BMK/Skyfall/BlackMarket) + แนบรูป + พิมพ์ชื่อผู้เล่นได้สูงสุด 10 ช่อง (แต่ละช่องพิมพ์บางส่วนแล้วเลือกจากที่ระบบเดาให้ได้เลย ไม่ต้องพิมพ์ให้ตรงเป๊ะ) **ส่งเข้าห้องตรวจสอบตามกิจกรรมที่เลือก** (แต่ละกิจกรรมมีห้องของตัวเอง ตั้งค่าได้ใน `.env`)
- แอดมินกดปุ่ม ✅ อนุมัติ (ทุกคนที่เลือกไว้ได้แต้มพร้อมกันตามกิจกรรม) หรือ ❌ ปฏิเสธ ในห้องตรวจสอบ
- `/score ชื่อ` — เช็คแต้มสะสม พิมพ์บางส่วนของชื่อแล้วระบบจะเดาชื่อให้เลือก (หาชื่อตัวเองง่ายขึ้น)
- `/scoreboard` — ดูอันดับ 25 อันดับแรก
- `/addscore ชื่อ จำนวน` — แอดมินปรับแต้มมือ (ไม่ต้องมีรูป)

**แต้มที่ได้ต่อกิจกรรม (ตั้งไว้ในโค้ด แก้ตัวเลขได้ที่ตัวแปร `ACTIVITY_POINTS` ใน `bot.py`):**
| กิจกรรม | แต้ม/คน |
|---|---|
| Airdrop | 3 |
| BMK | 2 |
| Skyfall | 2 |
| BlackMarket | 1 |

**รายชื่อผู้เล่นเริ่มต้น:** ระบบจะสร้างชื่อ "คนที่1" ถึง "คนที่25" ให้อัตโนมัติตอนรันครั้งแรก ใช้คำสั่ง `/renameplayer คนที่1 ชื่อจริง` ไล่เปลี่ยนทีละคนได้เลย (แต้มที่มีอยู่แล้วจะไม่หายไปไหน)

ข้อมูลเก็บในไฟล์ `data/scores.json` อัตโนมัติ ไม่ต้องตั้งฐานข้อมูลเพิ่ม

## ขั้นตอนที่ 1: สร้างบอทใน Discord Developer Portal

1. ไปที่ https://discord.com/developers/applications แล้วกด **New Application** ตั้งชื่อบอท
2. เข้าเมนู **Bot** ทางซ้าย > กด **Reset Token** เพื่อได้ Token (เก็บเป็นความลับ ห้ามแชร์ใครเด็ดขาด)
3. เลื่อนลงมาเปิด **Server Members Intent** ให้เป็น ON (จำเป็นสำหรับเช็คสิทธิ์แอดมิน)
4. เข้าเมนู **OAuth2 > URL Generator**
   - Scopes: เลือก `bot` และ `applications.commands`
   - Bot Permissions: เลือก `Send Messages`, `Embed Links`, `Attach Files`, `Read Message History`, `Use Slash Commands`
   - คัดลอกลิงก์ที่ได้ด้านล่าง แล้วเปิดในเบราว์เซอร์เพื่อเชิญบอทเข้าเซิร์ฟเวอร์ของคุณ

## ขั้นตอนที่ 2: ตั้งค่าไฟล์ .env

1. คัดลอก `.env.example` เป็นไฟล์ชื่อ `.env`
2. ใส่ `DISCORD_TOKEN` ที่ได้จากขั้นตอนที่ 1
3. เปิด Developer Mode ใน Discord (User Settings > Advanced > Developer Mode)
4. สร้างห้อง (หรือใช้ห้องที่มีอยู่) สำหรับแต่ละกิจกรรม แล้วคลิกขวา > Copy Channel ID ใส่ให้ครบทั้ง 4 ค่า:
   `REVIEW_CHANNEL_BLACKMARKET`, `REVIEW_CHANNEL_AIRDROP`, `REVIEW_CHANNEL_BMK`, `REVIEW_CHANNEL_SKYFALL`
   (จะใช้ห้องเดียวกันซ้ำกันหลายกิจกรรมก็ได้ ถ้ายังไม่อยากแยกทุกกิจกรรม)
5. (ไม่บังคับ) ถ้ามีโรลแอดมินเฉพาะ ใส่ชื่อโรลนั้นใน `ADMIN_ROLE_NAME`

## ขั้นตอนที่ 3: รันบอทบนเครื่องตัวเอง (ทดสอบก่อน)

```bash
pip install -r requirements.txt
python bot.py
```

ถ้าขึ้น `บอทออนไลน์แล้วในชื่อ ...` แปลว่าใช้งานได้แล้ว ลองพิมพ์ `/loop` ในเซิร์ฟเวอร์ดูได้เลย

## แนะนำที่ฝากรันฟรี/ราคาถูก

บอทต้องรันตลอดเวลา (24 ชม.) เครื่องคอมส่วนตัวจะไม่สะดวกถ้าปิดเครื่องบ่อย ตัวเลือกที่แนะนำ:

| ที่ฝาก | ราคา | ข้อดี | ข้อควรรู้ |
|---|---|---|---|
| **Railway.app** | มี trial ฟรีให้เครดิตช่วงแรก จากนั้น ~$5/เดือน | ตั้งค่าง่ายมาก เชื่อม GitHub แล้ว deploy อัตโนมัติ | เหมาะกับบอทขนาดเล็ก-กลางที่สุด |
| **Fly.io** | มี free allowance เล็กๆ | เสถียร รันได้จริง 24 ชม. | ตั้งค่าซับซ้อนกว่า Railway นิดหน่อย |
| **VPS ราคาถูก** (เช่น Oracle Cloud Free Tier, Contabo) | ถูกมากหรือฟรีตลอดชีพ (Oracle) | คุมได้เต็มที่ รันได้ตลอดจริง | ต้องตั้งค่า Linux เองทั้งหมด |
| Replit + UptimeRobot | ฟรี (แบบ hack) | ตั้งง่าย | ไม่เสถียรเท่าไหร่ บอทอาจหลับ/หลุดบ่อย ไม่แนะนำสำหรับงานจริง |

**คำแนะนำ:** เริ่มจาก **Railway.app** ก่อนจะง่ายที่สุด — แค่ push โค้ดขึ้น GitHub แล้วเชื่อมกับ Railway, ใส่ Environment Variables (DISCORD_TOKEN, REVIEW_CHANNEL_ID) ในหน้าเว็บ Railway แทนไฟล์ .env แล้วมันจะรันให้อัตโนมัติ

ถ้าอยากได้ขั้นตอน deploy ขึ้น Railway แบบละเอียดเป็นสเต็ปๆ บอกได้เลยครับ เดี๋ยวจัดให้
